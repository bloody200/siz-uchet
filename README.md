# Учёт СИЗ — автономный прототип

Локальное веб-приложение для учёта средств индивидуальной защиты (СИЗ) на предприятии.
Работает без установки и без сервера: один файл `index.html` открывается в любом браузере.

## Запуск

Скачайте `index.html` и откройте двойным кликом в браузере (Chrome, Edge, Firefox).
Ничего устанавливать не нужно. Данные хранятся локально в браузере (localStorage).

Для быстрого знакомства: раздел **«Данные и настройки» → «Загрузить демо-данные»**.

## Возможности

- Справочники: сотрудники (с размерами), номенклатура СИЗ (со сроком носки).
- Документы: поступление (приёмка) со сроками годности, выдача с авторасчётом
  даты окончания срока, списание со склада и у сотрудников.
- Контроль: блокировка выдачи просроченных СИЗ, контроль остатков на складе.
- Личные карточки сотрудников (по мотивам приложения № 2 к Правилам,
  утв. приказом Минтруда от 29.10.2021 № 766н) с печатью и CSV.
- Отчёты: выдача за период, истекающие сроки (30/60/90 дней), остатки на складе.
  Все отчёты выгружаются в CSV (открывается в Excel).
- Цветовая индикация: красный — просрочено (нельзя использовать), жёлтый — истекает.
- Перенос данных между компьютерами: экспорт/импорт базы в JSON.

## Ограничения прототипа

- Данные хранятся в localStorage текущего браузера; очистка данных браузера удалит базу.
- Учёт количественный (стоимостной учёт остаётся в учётной системе предприятия).
- Один пользователь; сетевого режима нет.
