# Учёт СИЗ — локальная программа с базой SQLite

Автономная программа учёта средств индивидуальной защиты (СИЗ) на предприятии.
Работает без установки и без сервера; все данные хранятся в файле базы SQLite (`.db`)
на диске пользователя. Учёт количественный.

## Варианты запуска

### 1. Онлайн-демо (GitHub Pages)

Этот репозиторий содержит многфайловую версию v0.3 для GitHub Pages: движок SQLite
(sql.js 1.12.0) подгружается с CDN jsDelivr, поэтому нужен доступ в интернет.

Включение Pages: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
После этого приложение доступно по адресу `https://<логин>.github.io/siz-uchet/`.

### 2. Офлайн-версия (один файл, рекомендуется для работы)

Однофайловая версия (~1 МБ) со вшитым движком SQLite работает полностью офлайн,
в т.ч. с `file://` в Chrome/Edge. Из-за размера она не хранится в репозитории и
распространяется отдельно.

## Работа с базой данных

- При первом запуске: **«Данные и настройки» → «Создать файл базы»** (или «Открыть файл базы»).
- Chrome / Edge: автосохранение всех изменений в файл `.db` (File System Access API).
- Firefox и др.: ручной режим — скачивание/загрузка файла `.db`.
- Файл `.db` — обычная база SQLite: копируется, открывается в DB Browser for SQLite;
  резервная копия = просто копия файла.
- Есть экспорт/импорт JSON и миграция данных из прототипа v0.1 (localStorage).
- Для быстрого знакомства: **«Данные и настройки» → «Загрузить демо-данные»**.

## Возможности

- Справочники: сотрудники (пол, рост, дата приёма, размеры одежды/обуви/головного
  убора/СИЗОД/СИЗ рук, привязка нормы выдачи), номенклатура СИЗ (срок носки,
  пункт норм ЕТН, модель/артикул).
- Нормы выдачи: справочник норм (наименование, пункт ЕТН, комплект СИЗ),
  автозаполнение документа выдачи по норме сотрудника с подстановкой размеров,
  отчёт «Обеспеченность нормами».
- Документы: поступление/приёмка (сроки годности партий), выдача (авторасчёт даты
  окончания срока, автоподстановка размеров из карточки сотрудника, блокировка
  просроченных СИЗ, контроль остатков, режим ручного ввода истории),
  списание/возврат (со склада или у сотрудника), продление срока носки (акт,
  печать МБ-8 «Акт на списание малоценных и быстроизнашивающихся предметов»,
  ОКУД 0320004).
- Печатные формы:
  - личная карточка по приложению № 2 к Правилам, утв. приказом Минтруда России
    от 29.10.2021 № 766н (лицевая и оборотная стороны);
  - МБ-6 «Личная карточка учёта СИЗ» (ОКУД 0320002);
  - МБ-7 «Ведомость учёта выдачи» (ОКУД 0320003) — печать прямо из документа выдачи;
  - МБ-8 «Акт на списание МБП» (ОКУД 0320004);
  - ведомость выдачи за произвольный период;
  - печатная заявка на закупку из отчёта «Потребность».

  Формы МБ-6/МБ-7/МБ-8 с 01.01.2013 необязательны (402-ФЗ) и применяются как шаблоны.
- Отчёты: выдача за период, истекающие сроки (30/60/90 дней), остатки на складе,
  обеспеченность нормами, потребность (заявка на закупку).
  Все отчёты выгружаются в CSV (открывается в Excel).
- Импорт сотрудников и номенклатуры из Excel (CSV) с шаблонами:
  **«Данные и настройки» → «Импорт из Excel (CSV)»**.
- Цветовая индикация и уведомления: красный — просрочено (выдача заблокирована),
  жёлтый — срок истекает.

## Структура репозитория

- `index.html` — оболочка приложения (стили, разметка, подключение скриптов);
- `js/app-1-db.js` — слой SQLite (sql.js с CDN), работа с файлом базы, миграция из v0.1;
- `js/app-2-core.js` — утилиты, расчёт остатков и сроков, печать, навигация;
- `js/app-3-views.js` — главная панель, справочники сотрудников, номенклатуры и норм;
- `js/app-4-docs.js` — документы: поступление, выдача, списание/возврат, продление;
- `js/app-5-forms.js` — печатные формы (766н, МБ-6, МБ-7, МБ-8, ведомость за период, заявка);
- `js/app-6-cards-reports.js` — личные карточки и отчёты;
- `js/app-7-data-init.js` — настройки, импорт CSV, демо-данные, инициализация.

## Ограничения

- Учёт количественный (стоимостной учёт остаётся в учётной системе предприятия).
- Один пользователь, без сетевого режима.
- Для автосохранения в файл нужен браузер с File System Access API (Chrome, Edge).

Программа подготовлена как проверка логики перед разработкой модуля (расширения)
для 1С:ERP Агропромышленный комплекс 2.
